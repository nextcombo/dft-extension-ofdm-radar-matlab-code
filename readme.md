# DFT Extension OFDM Radar [MATLAB Code]

In this project, the Discrete Fourier Transform Spreading (DFT-S) method, through simulations in MATLAB, is compatible with radar algorithms based on correlation and spectrum estimation using orthogonal frequency division multiplexing (OFDM) waveforms. It provides partial performance comparison to current wireless communication standards, such as IEEE 802.11a and 802.11p. Basic simulation runs for MIMO OFDM radar are conducted through MATLAB. This seems to indicate that using multiple transmit antennas can help increase the peak sidelobe ratio of the receiver, making the decision-making process easier.
